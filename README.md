# Mini Jochi

A virtual pet whose habits and history grow through everyday care.

[Mini Jochi at Burrito’s Labs](https://burritoslabs.com/catalogue/mini-jochi/)

## Technology

React, TypeScript, SVG, Cloudflare Workers, Supabase Auth and Postgres.

## Architecture

React and TypeScript present an animated SVG character. A Cloudflare Worker handles the app’s API, and Supabase Auth and Postgres keep each account and its pet’s progress associated.

## Product behavior

The same animated character is used across care and play. Care actions, food preferences and saved memories contribute to the companion’s history.
